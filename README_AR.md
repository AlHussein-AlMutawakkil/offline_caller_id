# حزمة التعديلات الشاملة — offline_caller_id

هذه الحزمة مبنية على **Commit 10** من المستودع `AlHussein-AlMutawakkil/offline_caller_id`. وهي حزمة Overlay وليست مشروع Flutter كاملًا؛ لذلك تُنسخ مجلداتها فوق المشروع المحلي الجديد فقط، ولا تُنسخ إلى `caller_id_app` القديم.

## ما تتضمنه الحزمة

تتضمن الحزمة فصل Controllers البحث بالاسم والرقم، وفصل Widgets الاستيراد، وتحديثًا للاستيراد ليعرض التقدم منذ بدء نسخ الملف ويمنع الاختيار المتكرر أثناء العملية. كما تتضمن قاعدة SQLite مستقلة باسم `telecom_companies.db`، وبيانات أولية لشركات يمن موبايل وسبأفون ويو وواي، مع إمكان الإضافة والتعديل والحذف والتفعيل من صفحة الإعدادات.

وتتضمن أيضًا ربط فلتر البحث بالاسم بالشركات الفعالة من قاعدة الشركات، وتطبيع أرقام الهاتف العربية والدولية قبل البحث، وإضافة فهارس SQLite على أعمدة `phone` و`names` عند إنشاء أو فتح قاعدة الأرقام. كما أُضيفت إعادة الاستيراد وحذف قاعدة الأرقام من الإعدادات، مع الحفاظ على الاستبدال الذري عبر ملف مؤقت حتى لا تُستبدل القاعدة الحالية بملف غير مكتمل إذا انقطع النسخ.

## التطبيق على Windows

بعد فك الضغط، انسخ محتويات مجلد `lib` داخل مجلد `lib` في المشروع المحلي، وبيانات `android` داخل مجلد `android` مع السماح باستبدال الملفات المطابقة. أو من داخل مجلد المشروع نفّذ نسخًا يدويًا مطابقًا لمسارات الحزمة. لا تستخدم الحزمة داخل المستودع القديم.

بعد النسخ، شغّل الأوامر التالية من مجلد المشروع المحلي:

```bat
flutter pub get
flutter analyze
flutter test
```

لا ترفع التعديلات إلى GitHub إلا بعد نجاح الأمرين الأخيرين والتجربة الفعلية على هاتف Android. بعد نجاح التجربة فقط يمكن تنفيذ:

```bat
git status
git add .
git commit -m "feat: complete architecture separation and settings"
git push
```

## ملاحظات Android

يحافظ Manifest المرفق على الصلاحيات المطلوبة واسم التطبيق العربي `كاشف الأرقام أوف لاين`، ولا يضيف تعريفات خدمات Android جديدة؛ وذلك لتجنب تعارض Manifest الذي ظهر سابقًا مع `flutter_background_service`. إذا ظهرت مشكلة Kotlin بعد التطبيق، تحقّق أولًا من وجود `resolutionStrategy` الموجود في `android/app/build.gradle` في Commit 10، ولا تضف تعريفات خدمة يدويًا.

## حدود التحقق في هذه البيئة

تم فحص جميع المسارات النسبية لملفات Dart آليًا، وتحققت الحزمة فوق نسخة مؤقتة من Commit 10 دون تغيير المستودع الأصلي. لم يتوفر Flutter SDK داخل بيئة التجهيز الحالية، ولذلك يجب تنفيذ `flutter analyze` و`flutter test` والتجربة على الهاتف من جهاز Windows الذي يحتوي على Flutter وAndroid SDK. لا يوجد أي Commit أو Push صادر من هذه الحزمة.

## الإضافات الجديدة في الواجهة

أضيفت قائمة جانبية مستقلة باسم `AppDrawer`. تظهر القائمة كـ Drawer في الشاشات الصغيرة، وتظهر كقائمة ثابتة بعرض مناسب في الشاشات الواسعة. وتحتوي على الرئيسية والبحث، وإدارة قاعدة البيانات، وشركات الاتصالات، والإعدادات.

أصبحت إعدادات المظهر محفوظة في قاعدة `app_settings.db` المحلية، وتدعم ثلاثة أوضاع: **نهاري**، **ليلي**، و**افتراضي حسب الجهاز**. كما أضيفت إعدادات مستقلة لإظهار أو إخفاء حالة قاعدة البيانات في الصفحة الرئيسية، وتشغيل التعرف على المتصل، وتشغيل النافذة العائمة، مع قسم خاص لطلب صلاحيات الهاتف والظهور فوق التطبيقات.

تم فصل صفحات `DatabaseManagementPage` و`TelecomCompaniesPage` و`SettingsPage`، بحيث لا تحتوي HomePage على منطق إدارة الشركات أو تفاصيل إعدادات الثيم. كما أُضيفت حدود عرض مناسبة لمحتوى البحث على الشاشات الكبيرة مع الحفاظ على قابلية الاستخدام في الهواتف.
